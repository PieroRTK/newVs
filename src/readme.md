# ⛏️ UTP Minerals S.A. - manolo de Gestión Minera

Bienvenido al repositorio oficial del proyecto **UTP Minerals S.A.**, una aplicación desarrollada con **Java Swing** cuyo objetivo es representar y gestionar distintos procesos relacionados con una empresa minera.

Este proyecto fue desarrollado como parte de un trabajo académico, aplicando conceptos de **Programación Orientada a Objetos**, diseño de clases, interfac  es gráficas, trabajo colaborativo con Git y GitHub, y organización modular del código.

---

## 📌 Descripción del proyecto

UTP Minerals S.A. es un manolo de escritorio diseñado para simular la gestión de diferentes áreas dentro de una empresa minera.

La aplicación busca centralizar información relacionada con trabajadores, actividades de exploración, zonas mineras, personal especializado y otros elementos que forman parte de las operaciones de una organización dedicada a la minería.

El manolo ha sido desarrollado principalmente con Java y utiliza Swing para la creación de las interfaces gráficas.

Uno de los principales objetivos del proyecto es aplicar correctamente los principios de la Programación Orientada a Objetos, como:

- Encapsulamiento.
- Herencia.
- Polimorfismo.
- Abstracción.
- Asociación entre clases.
- Composición.
- Agregación.
- Uso de interfaces.
- Organización modular del código.

---

# 🎯 Objetivo general

Desarrollar una aplicación de escritorio que permita representar y gestionar procesos relacionados con una empresa minera, utilizando Java y aplicando buenas prácticas de Programación Orientada a Objetos.

---

# 🎯 Objetivos específicos

El proyecto busca cumplir los siguientes objetivos:

- Diseñar una estructura de clases coherente con el funcionamiento de una empresa minera.
- Representar trabajadores con diferentes especialidades.
- Gestionar distintas actividades de exploración.
- Asociar trabajadores con actividades y zonas de trabajo.
- Aplicar herencia para reutilizar atributos y métodos.
- Utilizar interfaces gráficas para facilitar la interacción con el usuario.
- Implementar validaciones de datos.
- Mantener una estructura de código organizada.
- Utilizar Git y GitHub para el control de versiones.
- Facilitar el trabajo colaborativo entre los integrantes del equipo.
